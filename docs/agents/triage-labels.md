# Triage Labels

Use this mapping when an engineering skill names a triage role.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | Waiting for information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | Requires implementation by a human. |
| `wontfix` | `wontfix` | Will not be implemented. |

Change the label column if the repository adopts different label names.
